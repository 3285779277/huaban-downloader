# 花瓣独立下载

一个独立实现的 Edge / Chromium 扩展：鼠标悬停花瓣图片，或打开图片详情后按 **Z**，将图片直接保存到自己选择的文件夹。

## 功能

- 悬停缩略图按 Z 保存。
- 打开图片详情或标准图片弹窗后，按 Z 保存可见主图。
- 选择任意可授权的素材文件夹，不改变浏览器的默认下载位置。
- 输入框中打字不会触发下载。
- 图片直接写入目标文件夹，不出现在浏览器下载记录中。
- 无需依赖率叶插件。

## 安装

1. 下载本仓库 ZIP 并解压。
2. Edge 打开 `edge://extensions/`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择包含 `manifest.json` 的文件夹。
4. 刷新花瓣网页，点击右下角“选择素材文件夹”，并允许写入。
5. 悬停图片或进入图片详情，按 Z 下载。

使用时建议停用其他占用 Z 快捷键的扩展，避免重复下载。浏览器重启或授权失效后，可能需要重新授权文件夹。

更新扩展后，请先在 `edge://extensions/` 点击扩展的“重新加载”，再刷新所有已打开的花瓣网页。旧网页脚本的扩展连接会失效；若出现 `sendMessage` 或 `Extension context invalidated` 错误，刷新花瓣页面即可重新建立连接。“服务工作进程（不活动）”是空闲休眠状态，属于正常现象。

## 支持范围与限制

支持 HTTPS 花瓣页面，以及花瓣图片 CDN。下载时移除缩略图尺寸后缀（如 `_fw236`、`_fw658/format/webp`）和已知图片处理参数，保留认证参数，请求无缩放的图片地址。是否获得原图取决于实际链接和服务器响应；请求失败时显示错误，不回退下载缩略图。

详情页通过可见图片面积、标准弹窗识别主图；特殊布局可能识别错误。页面结构变化后可能需要调整选择逻辑。瀑布流预览界面支持框选批量下载。

不再人为限制单张图片大小。下载仍受浏览器内存和扩展消息传输容量限制，特别大的图片可能保存失败；失败时显示错误，不会自动改为下载缩略图。批量下载时继续处理其余图片。

## 隐私与权限

只申请访问花瓣和花瓣图片域名的权限。用户主动按 Z 时请求对应图片；仅向用户授权的文件夹写入文件。文件夹句柄保存在当前花瓣站点的 IndexedDB 中。没有统计、广告或额外上传服务。

## 开发

原生 JavaScript，Manifest V3，无构建步骤、无第三方依赖。

```sh
node --check background.js
node --check content.js
node --test image-url.test.js
```

这是独立项目，与花瓣或率叶无关联。

## 框选下载

按住鼠标左键拖动显示浅蓝色半透明选框，选中的图片会高亮。滚轮滚动时选框保留，按住左键可继续扩展范围。松开后按 Z 保存到已选择的素材文件夹，按 Esc 清除选区。

框选仅在瀑布流预览界面启用。进入单图详情页或标准图片弹窗时清除原有选区并禁用框选，此时按 Z 下载当前大图。选框随页面内容滚动，显示在顶部导航、目录等固定层下方。

批量下载依次保存图片，状态栏显示进度和最终成功、失败数量；单张失败会继续处理其余图片。下载后选区保留，再按 Z 会再次下载。重新拖动会替换选区，按 Esc 恢复悬停单图下载。

更新插件后，请在扩展管理页面点击“重新加载”，再刷新已打开的花瓣网页。

## 下载失败提醒

保存失败后，左下角弹出缩略图提醒。单张失败显示“此图片素材下载失败”，多张失败显示“多张图片下载失败”。鼠标移到缩略图上向右展开失败图片列表：当前图为 100%，下一张为 80%，再下一张为 60% 且部分露出，两侧使用对称透明渐隐遮罩。

在缩略图区域向下滚动切换下一张，向上滚动返回上一张；切换时图片向左或向右移动并调整大小。提醒同时显示当前序号和失败原因，点击 × 关闭。缩略图区域内滚动不会滚动网页。

### 2.1：缩略图下载

点击失败提醒框中的“缩略图下载”，将提醒框内全部失败图片按页面预览地址重新下载到所选素材文件夹，保留预览地址的缩放参数，不再请求原图。成功的图片从失败列表移除；仍然失败的图片保留并更新原因，全部成功后关闭提醒框。若页面预览地址本身就是原图地址，重试不会自动生成更小的图片。
